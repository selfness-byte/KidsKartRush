# 🏎️ 키즈 카트 러쉬! (Kids Kart Rush+)

카트라이더 러쉬플러스 스타일을 참조하여 어린이가 쉽고 신나게 즐길 수 있도록 제작한 **핸들(Steering Wheel) 컨트롤러 기반 3D 아케이드 레이싱 게임**입니다.

## ✨ 주요 특징
- **인터랙티브 핸들(Steering Wheel) 컨트롤러**: 왼쪽 파란 그립 / 오른쪽 빨간 그립 구분, 원형 회전·좌우 슬라이드·가장자리 터치 3중 하이브리드 인식, 중앙 듀얼톤 자동차 클락션(`📯 빵빵!`), 태블릿 기울이기(자이로) 핸들 모드 지원
- **박진감 넘치는 6대 동시 레이싱**: 다오, 디지니, 배찌, 우니, 마리드, 모비 등 5대의 라이벌 AI 카트가 내 바로 앞에서 앞서 달리거나 나란히 경쟁하며 부스터로 시원하게 추월하는 재미 제공
- **리얼 자동차 & 카트 레이싱 사운드 합성 엔진**:
  - 시동 크랭킹 & V6 배기 레브업 사운드 (`큐르르릉~ 부르르릉!`)
  - 속도(`km/h`) 및 1~5단 기어 변속 연동 실시간 연속 RPM 엔진 사운드
  - 드리프트/급코너 아스팔트 타이어 스키드 마찰음 (`끼이이익~!`)
  - 터보 블로우오프 밸브 + 니트로 제트 화염 부스터 폭발음 (`푸쉬익! 쿠아아앙~ 슈우우웅!`)
  - 앞차 추월 시 도플러 패싱 효과음 및 한국어 음성 응원(TTS)
- **어린이 안심 주행 도우미**: 자동 가속(Auto-Drive), 코너 자동 유도 도우미, 3단계 속도 조절(🐢 유아용 / 🚗 어린이용 / 🚀 초고속)
- **앱 내 자동 업데이트 (OTA)**: 앱 시작 시 및 대기실 상단 `[🔄 업데이트]` 버튼으로 `inanimals-1977.web.app` / `www.inanimals.co.kr` / GitHub 저장소에서 최신 APK를 확인하고 즉시 다운로드·설치
